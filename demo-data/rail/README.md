# ForgeMind Rail Synthetic Demonstration Dataset

This dataset was created solely for the Omnikon National Hackathon 2026
ForgeMind Rail demonstration.

It does not represent Indian Railways, a metro corporation, or any real
railway operator.

## Contents

| File | Description |
| --- | --- |
| `rail_asset_register.csv` | Synthetic rail asset register (8 assets) |
| `rail_inspections.csv` | Synthetic inspection records |
| `rail_usage.csv` | Synthetic usage/operational records |
| `rail_failures.csv` | Synthetic failure history |
| `rail_work_orders.csv` | Synthetic maintenance work orders |

## Asset IDs

All files use consistent `asset_id` values:

| asset_id | asset_type |
| --- | --- |
| TRK-001 | Track Section |
| SW-002 | Turnout |
| PM-003 | Point Machine |
| SIG-004 | Signal Relay |
| BRG-005 | Axle Bearing |
| TRM-006 | Traction Motor |
| WHL-007 | Wheelset |
| OCS-008 | Overhead Line Component |

## Disclaimer

> All data in this directory is **synthetic** and was generated for
> hackathon demonstration purposes only. It does not reflect real
> operational conditions, real failure rates, or real maintenance records.
